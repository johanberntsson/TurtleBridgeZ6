# TurtleBridgeZ6
Turtle Bridge on the Z machine

A Game & Watch style arcade game for Z-machine version 6. Carry packages across
the backs of five turtles, and don't be standing on one when it dives for a fish.

    make            # build and play in sfrotz
    make mega65     # build a MEGA65 disk image (Ozmoo) and run it in xemu

Keys: Z/X or the cursor keys to move, P to pause, Q to quit. A or B starts a game.
